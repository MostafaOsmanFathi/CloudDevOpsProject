# AWS-style architecture diagrams

The NTI/iVolve brief was written for AWS, but this deployment runs on **Azure**,
so these diagrams draw the *same* architecture with **AWS service names and the
official AWS Architecture Icons** (`mxgraph.aws4` stencils), and say which Azure
service is actually in use.

Generated by [`src/make_diagrams.py`](src/make_diagrams.py) — every `.drawio` is
committed next to its `.png`, so the images can be regenerated or edited.

The connector lines are 3.5 px with filled arrowheads. The animation overlays four
colour-coded flows on the static render: blue = user request, magenta = CI build
and push, violet = Argo CD sync, purple = ECR image pull. Packets follow the
exact orthogonal paths of the drawn edges.

## AWS name → what actually runs

| AWS name in the diagrams | Actual service | Notes |
| --- | --- | --- |
| Route 53 | Azure DNS / public-IP DNS label | `ivolve.denmarkeast.cloudapp.azure.com`, `ivolve-argocd.denmarkeast.cloudapp.azure.com` — free Microsoft names |
| Elastic IP | Azure Public IP | 3 of 3 regional slots used (app, NAT gateway, Argo CD) |
| EC2 (Jenkins · nginx · Docker · Trivy) | Azure Linux VM `ivolve-jenkins-server` | `Standard_B2s`, 2 vCPU; runs nginx, cloudflared, and the CI tooling |
| VPC 10.0.0.0/16 | Azure VNet `ivolve-vnet` | public 10.0.0.0/24 + 10.0.1.0/24, private 10.0.10.0/24 + 10.0.11.0/24 |
| Internet Gateway / NAT Gateway | Azure Internet access / NAT gateway | NAT gateway is egress-only |
| Security Group / Network ACL | Azure NSG (NIC + subnet) | NIC rules: 22, 80, 8080; subnet rules: 22, 80, 443 |
| EKS | Azure AKS `ivolve-aks` | system pool `Standard_DS3_v2` ×1; user node pools 0 nodes (6-vCPU regional quota) |
| EKS worker node | AKS node | Azure CNI, pod IPs from the VNet |
| ECR | Azure ACR `ivolveacrgf7a4e` + Docker Hub | images are built and pushed by CI |
| S3 + DynamoDB | Azure Blob (Terraform backend) | blob lease replaces the DynamoDB lock table |
| EBS (gp3) | Azure Managed Disk (`StandardSSD_LRS`) | StorageClass `ivolve-storage`, Azure Disk CSI |
| CodeCommit | GitHub `MostafaOsmanFathi/CloudDevOpsProject` | path `kubernetes/` |
| CodeBuild / CodePipeline | GitHub Actions (`image-ci.yml`) | build, Trivy scan, push, then update `kustomization.yaml` and push |
| Argo CD | Argo CD v3.6.1 (Helm) in the cluster | Application `ivolve`, automated sync + self-heal |
| CloudWatch | — | not deployed |

## End-to-end flow

```
push to main
  → GitHub Actions builds, scans (Trivy) and pushes  mostafaosmanfathi/<service>:sha-<commit>
  → the gitops job rewrites images[].newTag in kubernetes/kustomization.yaml and pushes [skip ci]
  → Argo CD sees the new revision, syncs and rolls the Deployments
  → browser → Route 53 name → nginx on the EC2 → NodePort 30300 → frontend → auth / roadmap → MySQL
```
